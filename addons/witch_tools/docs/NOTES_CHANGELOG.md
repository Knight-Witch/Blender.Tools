# Witch Tools Notes Changelog — Latest Update

Date: 2026-08-18

## Dev_v2.11.4 — exact 3D Print Toolbox Analyze bridge

- User retesting in Blender 5.0.1 confirmed the Dev_v2.11.3 STL export hotfix now creates the STL successfully.
- The same `_CAP 3` retest proved Analyze still disagreed with the original 3D Print Toolbox: Toolbox Non-flat 98 / Overhang 79 versus Witch Tools Non-flat 73 / Overhang 80. The remaining displayed fields matched on this fixture.
- Removed the parallel Witch Tools Analyze detector instead of attempting another algorithm rewrite.
- Witch Tools `Check All` now invokes the installed 3D Print Toolbox `mesh.print3d_check_all` operator directly and mirrors the live report generated by that extension.
- In Edit Mode, non-empty selectable Witch Tools result buttons now invoke the original Toolbox `mesh.print3d_select_report` with the original live report index, restoring the Toolbox click-to-select pipeline.
- Analyze no longer substitutes Witch Tools thresholds, BMesh/BVH checks, normals math, thickness rays, or a fallback detector. If the Toolbox backend/report is unavailable, Witch Tools reports an explicit error.
- Analyze therefore deliberately depends on the 3D Print Toolbox extension being installed/enabled. Other Witch Tools 3D-print features remain independent.
- Added/updated Dev_v2.11.4 version metadata, compatibility record, build validation, project/feature state, roadmaps, UI map, spec, decisions, test plan, changelogs, and compatibility documentation.
- Primary target remains Blender 5.0.1; Blender 4.5 remains secondary compatibility.
- Runtime gate: original Toolbox and Witch Tools must display identical counts on the unchanged `_CAP 3`, then their Edit Mode result buttons must select the exact same elements.
